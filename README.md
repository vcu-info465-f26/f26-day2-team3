# ACC FBS Standings

Interactive Streamlit dashboard for the latest ACC standings in the checked-in snapshots. The team filter updates the wins chart, losses chart, and standings table.

Public deployment: [Deploy on Streamlit Community Cloud](https://share.streamlit.io/deploy?repository=vcu-info465-f26%2Ff26-day2-team3&branch=main&mainModule=src%2Fapp.py); choose Public visibility.
Public dashboard URL: Pending Community Cloud deployment.

Run locally: `python -m pip install -r requirements.txt`
Launch: `streamlit run src/app.py`
